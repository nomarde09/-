# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

## О проекте

Простой watchlist фильмов и сериалов со статусами. Подробное описание, цели и открытые вопросы — в `PROJECT.md`. Краткое описание для GitHub — в `README.md`.

## Язык

- Общение, комментарии в документации и сообщения коммитов — на русском языке.
- Названия переменных, функций и файлов в коде — на английском языке.

## Правила работы

- Перед большими изменениями сначала коротко объясни план, потом делай.
- Не добавляй зависимости и не меняй стек без подтверждения. Стек: HTML + CSS + JavaScript без библиотек, данные в `localStorage` (см. `PROJECT.md`).
- Не коммить файлы с паролями, ключами и `.env` — они уже в `.gitignore`, и их нужно оставлять там.
- Не удаляй и не перезаписывай чужие файлы без подтверждения.

## Git

- Основная ветка — `main`.
- Сообщения коммитов — короткие и понятные, на русском: что изменено и зачем.
- Перед коммитом проверяй, что в нём нет секретов: `git status` и `git diff --staged`.

## Команды

- Запуск: открыть `index.html` в браузере (двойным кликом). Сервер не нужен.
- Сборка: не нужна.
- Тесты: пока нет. Проверка вручную в браузере, ошибки смотреть в консоли (F12 → Console).

## Что обновлять

Когда меняются цели, функции или стек, обнови `PROJECT.md`. Когда меняется способ запуска, обнови раздел «Как запустить» в `README.md`.
