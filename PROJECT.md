# PROJECT.md — Watchlist фильмов и сериалов

## Цель

Сделать простой watchlist: пользователь добавляет фильм или сериал, выбирает статус «Хочу посмотреть / Смотрю / Просмотрено», потом находит запись и меняет статус. Это первый учебный проект, поэтому всё делается максимально просто. Аналитика просмотров — возможное развитие на будущее, не сейчас.

## Основные функции

- Добавление записи: название и тип (фильм или сериал).
- Статус записи: «Хочу посмотреть», «Смотрю», «Просмотрено». Новая запись по умолчанию — «Хочу посмотреть».
- Изменение статуса.
- Поиск по названию.
- Сохранение списка между открытиями страницы.

## Стек

- HTML, CSS и JavaScript без библиотек и фреймворков.
- Без сервера и базы данных: данные хранятся в браузере (`localStorage`).
- Сборка и установка не нужны: сайт открывается файлом `index.html`.

## Структура

```
index.html   — разметка страницы
style.css    — внешний вид
app.js       — логика: добавление, поиск, смена статуса, сохранение
```

Формат одной записи:

```js
{ id: 1730721600000, title: "Дюна", type: "movie", status: "want" }
// type: "movie" | "series"
// status: "want" | "watching" | "watched"
```

## План

1. ✅ Пустая страница с подключёнными `style.css` и `app.js`.
2. Форма добавления (только разметка).
3. Добавление записи в список на странице.
4. Сохранение в `localStorage`.
5. Статус у каждой записи и его изменение.
6. Поиск по названию.
7. Фильтр по статусу (по желанию).
8. Оформление.
9. Удаление записи (по желанию).

## Планы на будущее

- Аналитика просмотров (что смотрел, когда, оценки, статистика) — после того, как заработает watchlist.

## Что пока не добавляем

- Фреймворки, сборщики, npm-пакеты.
- Сервер, базу данных, регистрацию и вход.
- Внешние API с данными о фильмах (постеры, описания).
- Аналитику и графики.
- Оценки, отзывы, жанры, сезоны и серии.
- Редактирование названия, сортировку, импорт и экспорт.
- Адаптивный дизайн, тёмную тему, анимации.
- Тесты и публикацию в интернете.

## Что пока не решено

- Где разместить сайт, когда он будет готов (например, GitHub Pages).
- Добавлять ли аналитику просмотров после того, как заработает watchlist.
