# Тестовый сайт — watchlist фильмов и сериалов

Простой список фильмов и сериалов со статусами «Хочу посмотреть», «Смотрю» и «Просмотрено». Можно добавить запись, найти её и изменить статус.

Сделан на HTML, CSS и JavaScript без библиотек. Данные хранятся в браузере.

Проект в начальной стадии.

## Как запустить

Откройте файл `index.html` в браузере (двойным кликом). Установка и сервер не нужны.
